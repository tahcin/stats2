Probability: Independence Check

Are variables X & Y playing their own game, or influencing each other? Let's find out.

// Key Concepts //

  • Joint P(X=x, Y=y): Chance of BOTH.
  • Marginal P(X=x): Chance of just X (sum over Y).
  • Test: Independent if `P(x,y) == P(x) * P(y)` for ALL pairs.

Example_Quest:

Joint PMF: P(1,1)=0.1, P(1,2)=0.2, P(2,1)=0.3, P(2,2)=0.4. Independent?

Solution_Steps:

1. Calc Marginals:

P(X=1) = 0.1 + 0.2 = 0.3 P(X=2) = 0.3 + 0.4 = 0.7 P(Y=1) = 0.1 + 0.3 = 0.4 P(Y=2) = 0.2 + 0.4 = 0.6

2. Test P(1, 1):

Is P(1, 1) == P(X=1) * P(Y=1) ? Is 0.1 == 0.3 * 0.4 ? Is 0.1 == 0.12 ? >> NO.

Output: Variables are DEPENDENT.

Further details:

  • This failure means dependence.
  • No need to check other pairs.
  • Independence requires equality for ALL combinations.

Hypothesis Test: The Verdict

Using data evidence to judge a claim (the Null Hypothesis).

// Key Players //

  • H₀: The default claim (no effect).
  • Hₐ: The challenge (is effect).
  • Test Stat: Evidence score.
  • p-value: Chance of evidence if H₀ true.
  • Alpha (α): Your 'doubt' threshold (e.g., 0.05).
  • Rule: If `p < α`, Reject H₀.

Example_Quest:

Claim: Avg time <= 5 min. Sample avg = 5.8 min. p-value = 0.027. Use α = 0.05.

Solution_Steps:

1. Hypotheses:

H₀: μ ≤ 5 Hₐ: μ > 5

2. Compare:

p-value (0.027) < α (0.05) >> YES.

Output: Reject H₀. Evidence supports avg time > 5 min.

Notes:

  • Rejecting H0 doesn't prove H_a is true, just that H0 is unlikely.
  • Failing to reject H0 doesn't mean H0 is true, just not enough evidence.
// Ref: Q2, Q3, Q4, Q5

Chi-Square Tests: Category Check

Comparing observed counts to expected counts in tables.

// Flavors & Formula //

χ² = Σ [ (Obs - Exp)² / Exp ]
  • Independence: Related? Exp=(Row*Col)/Grand. DoF=(r-1)(c-1).
  • Goodness-of-Fit: Match pattern? Exp=Hypothesis. DoF=(k-1).

Example_Quest (GoF):

Claim: 4 drinks equal preference. N=80. Obs: A(25), B(15), C(22), D(18). Calc χ².

Solution_Steps (GoF):

1. H₀: P_A=P_B=P_C=P_D=0.25. Hₐ: Not equal.

2. Expected: 80/4 = 20 per drink.

3. Calc χ² parts:

A: (25-20)²/20 = 1.25 B: (15-20)²/20 = 1.25 C: (22-20)²/20 = 0.20 D: (18-20)²/20 = 0.20

4. Sum:

χ² = 1.25 + 1.25 + 0.20 + 0.20 = 2.90

Output: χ² = 2.90 (DoF=3).

  • Compare this to a critical value from χ² table with DoF=3 and chosen α.

Example_Hint (Independence):

Cell(1,1): Obs=50. RowT=120, ColT=80, GrandT=300.

Exp(1,1) = (120*80)/300 = 32 Contrib(1,1) = (50-32)²/32 = 10.125

(Sum contributions for all cells).

Wilcoxon Test: Rank Check

Non-parametric test using ranks for related data or vs median.

// The_Mission //

  • Calc Diffs. Ignore 0s. Rank |Diffs| (Avg ties). Sum (+)Ranks (W+), |(-)Ranks| (W-).
  • H₀: Median difference = 0.

Example_Quest (Paired):

Scores Before->After: E1:70->75, E2:60->68, E3:80->78, E4:65->65. Calc W+.

Solution_Steps:

Table of Calculations:

EmployeeBeforeAfterDifference|Abs Diff|RankSigned Rank
17075+552+2
26068+883+3
38078-221-1
465650(Ignore)--

Explanation: n=3. Ranks of |Diffs|={5,8,2} are {2,3,1}.

Calc W+:

W+ = Sum(+)Ranks = 2 + 3 = 5

Output: W+ = 5.

  • The test statistic is usually the smaller of W+ and W- (which is W-=1 here).
  • Compare test statistic to critical value for n=3.

Regression: Line Fitter

Using lines to predict Y from X and check model fit.

// Key_Concepts //

  • SLR: `Y = β₀ + β₁X`.
  • Slope β₁: Change Y per unit X.
  • Adj R²: Better model compare tool.

Example_Quest (SLR):

Model: `Sales = 10 + 2.5 * Temp`. Predict for Temp=20. Slope meaning?

Solution_Steps:

1. Predict:

Sales = 10 + 2.5 * (20) = 10 + 50 = 60

Output: Predicted sales = 60.

2. Slope Meaning (β₁ = 2.5):

Each 1°C increase in Temp predicts a 2.5 unit increase in Sales.

  • β₀=10 is the predicted sales at 0°C.

Logistic Reg: Odds Predictor

Predicting Yes/No (1/0) outcomes via log-odds.

// How_It_Works //

  • Model: `Log-odds = β₀ + β₁X₁...`
  • Coef β₁: 1-unit X increase multiplies *ODDS* by `exp(β₁)`.
  • Convert: `Prob = 1 / (1 + exp(-LogOdds))`.

Example_Quest:

Model: `LogOdds = 5 - 0.01*Score`. Calc LogOdds & Prob for Score=600. Interpret coef -0.01.

Solution_Steps:

1. Calc LogOdds:

LogOdds = 5 - 0.01 * (600) = 5 - 6 = -1

2. Calc Prob (p):

p = 1 / (1 + exp(-(-1))) = 1 / (1 + exp(1)) p = 1 / (1 + 2.718) = 1 / 3.718 ≈ 0.269

Output: Prob ≈ 26.9%.

3. Interpret Coef (β₁ = -0.01):

Each 1 point Score increase multiplies *odds* of default by `exp(-0.01)` ≈ 0.99 (odds decrease ~1%).

  • Odds = p / (1-p).
  • Log-odds = ln(Odds).

Forecasting: Future Gazer

Using past data to predict what's next.

// Common_Tools //

  • Simple Avg: Mean of all past data.
  • Weighted Avg: Σ (Weight * Value).
  • Exp Smoothing: `NewF = α*Actual + (1-α)*OldF`.

Example_Quest (Weighted Avg):

Sales (recent first): 100, 90, 110. Weights: 0.5, 0.3, 0.2. Forecast?

Solution:

Forecast = (0.5*100) + (0.3*90) + (0.2*110) Forecast = 50 + 27 + 22 = 99

Example_Quest (Exp Smoothing):

LastF=500, Actual=550. Use α=0.2. New Forecast?

Solution:

NewF = 0.2*(550) + (1-0.2)*(500) NewF = 110 + 0.8*500 = 110 + 400 = 510
  • Alpha (α) controls smoothing. High α = more reactive.

Decision Making: Path Chooser

Choosing actions with uncertain or risky futures.

// Strategies //

  • Maximax: Optimist (Max of Maxes).
  • Maximin: Pessimist (Max of Mins).
  • Hurwicz(α): Mix (Max of `α*Best+(1-α)*Worst`).
  • EMV: Risk (Max of `Σ(Prob*Payoff)`).

Payoff Table ($k):

Outputs by Criterion:

  • Maximax: Choose A1 (Max=100).

Evaluation: Model Grader

Checking how well classification models perform.

// Key_Metrics //

  • Precision: `TP / (TP + FP)`.
  • Recall: `TP / (TP + FN)`.
  • F1-Score: `2*(Prec*Rec)/(Prec+Rec)`.

// Decision_Trees //

Split data on features for purity (Info Gain/Gini).

Example_Quest (F1):

Confusion Matrix:

Actual PositiveActual Negative
Predicted Positive80 (TP)20 (FP)
Predicted Negative10 (FN)90 (TN)

Calculate F1-Score.

Solution_Steps:

1. Precision:

Prec = TP / (TP + FP) = 80 / (80+20) = 0.80

2. Recall:

Rec = TP / (TP + FN) = 80 / (80+10) ≈ 0.889

3. F1-Score:

F1 = 2*(Prec*Rec)/(Prec+Rec) F1 = 2*(0.80*0.889)/(0.80+0.889) ≈ 0.842

Output: F1 ≈ 0.842.

  • High F1 means good balance of precision and recall.

Parametric vs Non-Parametric

Parametric tests need data assumptions (e.g., normal); Non-parametric are flexible.

// The_Difference //

  • Parametric: Assume distribution (t-test).
  • Non-Parametric: Fewer assumptions (Wilcoxon).

Example_Quest:

Compare median income (skewed data) between 2 cities (independent samples). Which test?

  1. Independent t-test
  2. Mann-Whitney U test

Solution:

Skewed data violates t-test normality. Mann-Whitney U is the non-parametric alternative for independent samples.

Output: Choose Mann-Whitney U test (Option 2).

  • Non-parametric tests often use ranks.
